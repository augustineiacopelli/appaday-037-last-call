# appaday-037-last-call
Last Call is a Pac-Man-style arcade game with a taproom twist. Sweep barley kernels and bonus pretzels as a bartender, dodging four barflies with classic chase, ambush, patrol, and flee AI. Hop cones turn the tables for a hunt. Four themed levels — Tap Room, Biergarten, Nightclub, Venue — with rising difficulty and bonus lives.
